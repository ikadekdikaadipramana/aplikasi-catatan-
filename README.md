## Deskripsi Aplikasi
Aplikasi Catatan merupakan aplikasi Android untuk membuat, menyimpan, dan mencari catatan. Aplikasi ini dibuat menggunakan Kotlin, Jetpack Compose, dan Room Database.

## Fungsi Berkas
- **MainActivity.kt**: Halaman utama aplikasi.
- **Catatan.kt**: Menyimpan struktur data catatan.
- **CatatanDao.kt**: Mengatur operasi data catatan.
- **AppDatabase.kt**: Mengatur database lokal.
- **CatatanRepository.kt**: Menghubungkan database dengan ViewModel.
- **CatatanViewModel.kt**: Mengatur data dan logika aplikasi.
- **Layar.kt**: Menampilkan antarmuka aplikasi.
- **KomponenCatatan.kt**: Komponen tampilan catatan.
- **LayarProfil.kt**: Menampilkan halaman profil.
- **AndroidManifest.xml**: Mengatur konfigurasi aplikasi.
- **build.gradle.kts**: Mengatur konfigurasi build dan dependensi.
- **settings.gradle.kts**: Mengatur konfigurasi project.
- **gradle.properties**: Menyimpan pengaturan Gradle.
- **libs.versions.toml**: Mengatur versi library yang digunakan.
